# Contributing to CodeQuest

Thanks for helping make high-quality coding education free.

## Curriculum contribution checklist

- State language version, runtime and prerequisites.
- Write original explanations and examples; respect source licences.
- Include measurable objectives, a worked example and practice that requires learners to write or debug code.
- Explain common mistakes and why incorrect answers are incorrect.
- Include boundary cases, tests and a spaced-retrieval checkpoint.
- Avoid claiming a short course guarantees employment.
- For Roblox, distinguish client-side display from server-authoritative logic and validate remote requests.
- For security topics, teach safe defaults and explain why they matter.

## Development

This is a static HTML/CSS/JavaScript app with no build step. Test at mobile sizes and with keyboard-only navigation. Keep progress local unless an optional, free and privacy-reviewed sync architecture is proposed. Never execute arbitrary learner code on the static site origin.
