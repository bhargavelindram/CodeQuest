# Curriculum authoring guide

The current app exposes an 11-stage roadmap for each technology. Each track still needs dedicated, reviewed lessons and exercises before it can credibly claim professional or hiring readiness.

Every module should include:
- Language/runtime versions and prerequisite concepts.
- Measurable learning outcomes.
- Original explanation and worked example.
- Practice that requires the learner to produce or debug code.
- Feedback for incorrect approaches.
- Automated tests including boundaries and malformed input.
- Spaced retrieval and a small deliverable or mastery rubric.
- Estimated time range, never a forced timer.

## Suggested stages

1. Environment and mental model
2. Values, types and expressions
3. Control flow
4. Functions and decomposition
5. Collections and data modelling
6. Errors, debugging and testing
7. Files, libraries and APIs
8. Algorithms and complexity
9. Architecture and design
10. Security, performance and reliability
11. Capstone, review and portfolio evidence

Frameworks should have explicit prerequisites: React depends on JavaScript fundamentals; TypeScript builds on JavaScript; HTML and CSS are related but distinct; SQL supports many backend paths. Keep standard Lua separate from Roblox Luau, whose platform APIs and client/server model require dedicated instruction.
